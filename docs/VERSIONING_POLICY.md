# QuillSpark Semantic Versioning Policy

QuillSpark uses MAJOR.MINOR.PATCH for released glossary versions.

- MAJOR: incompatible schema or terminology-policy changes.
- MINOR: new human-approved terms or backward-compatible glossary additions.
- PATCH: non-semantic spelling, metadata, or documentation corrections.

Draft work uses a pre-release identifier such as `0.1.0-draft`. A stable release must contain only entries approved under the human-review policy. Never tag a draft-only candidate set as a stable approved glossary.
