# QuillSpark Release Checklist

- [ ] Review all candidate terms with a human reviewer.
- [ ] Check consistency against `glossary/bn-it-glossary.json`.
- [ ] Confirm all terms included in the stable export are approved.
- [ ] Validate YAML, CSV parity, and JSON Schema.
- [ ] Review duplicate IDs and English terms.
- [ ] Update `VERSION` and `CHANGELOG.md`.
- [ ] Merge the reviewed pull request.
- [ ] Create a version tag and GitHub Release only after approval.
- [ ] Mark a release containing draft-only candidates as a pre-release, never as a stable approved glossary.
